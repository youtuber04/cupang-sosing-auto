# cupang-sosing-auto — 쿠팡 판매량순 소싱 자동화 (Claude Code 스킬)

쿠팡에서 **판매량순 1위(광고 제외)** 상품을 사람처럼 직접 골라 저장하고, 쿠팡 파트너스 간편링크를 딥링크 API 한 번으로 만드는 Claude Code 스킬입니다. 쿠팡 **검색 API를 쓰지 않아** 시간당 한도(3회 초과 시 파트너스 이용 제한)에 걸리지 않고, 딥링크도 안전장치가 한도 전에 막습니다.

## 설치
1. 이 저장소를 내려받아 폴더째 `%USERPROFILE%\.claude\skills\cupang-sosing-auto` 에 넣습니다.
2. `.env.example` 을 복사해 `.env` 로 만들고 본인 쿠팡 파트너스 키를 넣습니다(선택 — 없으면 링크만 나중에).
3. Claude 데스크톱 앱(Code 탭)에서 "쿠팡 소싱" 또는 `/cupang-sosing-auto` 로 실행합니다.

## 들어 있는 것
| 파일 | 하는 일 |
|---|---|
| `SKILL.md` | Claude 가 따르는 순서·규칙 |
| `scripts/coupang_sales_pick.js` | 쿠팡 판매량순 검색 화면에서 상품 목록(순위·광고 여부·상품번호·이름·가격·리뷰수·사진) 뽑기 |
| `scripts/coupang_browser_pick.py` | 고른 상품 정보·대표사진 저장 + 간편링크 |
| `scripts/coupang_api.py` | 쿠팡 딥링크 API + 한도 보호 안전장치 |
| `scripts/sourcing_plan.py` | 소싱 순서 관리(1단계 최근 1달 → 2단계 2달 뒤 → 3단계 욕실·주방·거실), 부피 큰 제품 제외 |
| `references/guide.md` | 사람이 읽는 자세한 지침 |

## 주의
- 키는 채팅에 붙여 넣지 말고 `.env` 에만 넣으세요. `.env` 는 깃에 올라가지 않습니다.
- 쿠팡이 화면을 막으면(보안 문자 등) 우회하지 않습니다.
- 쿠팡 파트너스 링크가 들어간 글에는 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." 문구를 꼭 넣으세요.
