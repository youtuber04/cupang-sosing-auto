# 쿠팡 판매량순 1위 상품으로 소싱하기 — 스킬 전달용 지침

이 지침을 받은 Claude는 영상으로 만들 상품을 **쿠팡에서 사람처럼 직접 검색해서** 고른다.
- 판매량순으로 정렬하고, **광고가 아닌 1위 상품**을 쓴다.
- 쿠팡 파트너스 **검색 API는 쓰지 않는다.** 보고는 전부 한국어로 한다.

## 왜 바꿨나
- 쿠팡 파트너스 검색 API는 시간당 횟수 제한이 있다.
- 한도를 넘기면 쿠팡이 이런 경고를 보낸다: "총 3회 초과시 파트너스 이용이 제한됩니다".
  - 3회를 넘기면 파트너스 계정이 막혀 링크를 아예 못 만든다.
- 그래서 상품 찾기는 브라우저 검색으로 하고, API는 링크 만들기(딥링크)에만 아껴 쓴다.

## 폴더에 든 파일
| 파일 | 하는 일 |
|---|---|
| `coupang_sales_pick.js` | 쿠팡 검색 화면에서 상품 목록(순위·광고 여부·상품번호·이름·가격·리뷰수·사진)을 뽑는다 |
| `coupang_browser_pick.py` | 고른 상품을 영상 작업폴더에 저장한다(상품 정보·간편링크·대표사진) |

`coupang_browser_pick.py` 는 스킬 폴더 `scripts/` 에 들어 있고, 간편링크는 같은 폴더의 `coupang_api.py`(딥링크 + 안전장치)로 만든다.

## 순서 (상품 하나마다)
1. **검색어 정하기**
   - 계절·목적에 맞는 키워드를 정한다. 예: 겨울이면 `손난로`, `전기요`, `차량 성에제거기`.
   - 이미 만든 상품과 겹치지 않게 한다.
2. **판매량순 검색**
   - Claude 앱 안 브라우저로 아래 주소를 연다.
     ```
     https://www.coupang.com/np/search?q=<검색어>&sorter=saleCountDesc
     ```
   - 사용자의 크롬이 아니라 Claude 앱 안 브라우저를 쓴다.
3. **목록 뽑기**
   - 페이지가 다 뜨면 2~3초 기다린다.
   - `coupang_sales_pick.js` 내용을 브라우저 JavaScript 실행 도구로 실행한다.
   - 결과의 `광고아닌1위` 가 고를 상품이다. 광고 상품은 순위가 높아도 건너뛴다.
4. **영상으로 보여 줄 수 있는지 확인**
   - 실제 사용 장면이 있는 상품을 고른다. 건전지·테이프처럼 시연 장면이 없는 소모품은 다음 순위로 넘긴다.
   - 해외 실사 영상 소스를 충분히 못 찾으면 그 상품은 버리고 다음 순위나 다음 키워드로 간다.
5. **저장**: 스킬 폴더에서 실행한다.
   ```bash
   python scripts/coupang_browser_pick.py "<작업폴더>" "<검색어>" "<주소>" "<상품명>" "<대표사진>" <가격>
   ```
   - `<주소>`, `<상품명>`, `<대표사진>`, `<가격>` 은 3번 결과의 `광고아닌1위` 값을 그대로 넣는다.
   - 저장되는 파일: `ref/쿠팡상품선택.json`, `ref/쿠팡간편링크.json`, `쿠팡대표사진.jpg`.
   - 대표사진은 자동으로 큰 사진(1000×1000)으로 받는다.
6. **간편링크**
   - 저장할 때 딥링크 API로 만든다. 검색 API는 쓰지 않는다.
   - 쿠팡 API가 "시간당 사용 횟수 초과"로 막혀 있으면 앞에 `NOLINK=1` 을 붙여 상품만 저장한다.
   - 제한이 풀린 시각 뒤에 같은 명령을 `NOLINK` 없이 다시 실행해 링크를 만든다.
   - 링크가 없는 동안은 업로드 설명란과 돈벌자 블록 등록을 미룬다.

## 쿠팡이 막았을 때
"요청하신 페이지의 사용권한이 없습니다", "Access Denied", 보안 문자 같은 화면이 나오면 이렇게 한다.
- **우회하거나 보안 문자를 풀지 않는다.** 같은 검색을 계속 반복하지도 않는다. 스크립트는 이때 `차단됨` 을 돌려준다.
- 사용자에게 알리고, 사용자가 허락한 다른 브라우저 도구로 같은 순서(2~3번)를 한다. 예: Aside 브라우저.
- 그것도 막히면 사용자에게 부탁한다.
  - 사용자가 직접 쿠팡에서 판매량순으로 검색한다.
  - 광고 아닌 1위 상품 주소를 채팅에 붙여 넣는다.
  - 그 주소로 5번부터 한다.

## 지킬 것
- 쿠팡 검색 API(`coupang.py search`, `lookup`, `link` 1단계)를 여러 번 부르는 반복 작업은 절대 돌리지 않는다.
  - 한도 초과 경고가 한 번이라도 나오면 그 시각까지 쿠팡 API를 전부 멈춘다.
- 검색은 사람 속도로 한다. 상품 하나에 검색 한두 번이면 되고, 여러 키워드를 한꺼번에 몰아서 검색하지 않는다.
- 상품 페이지의 파트너스 링크나 광고 링크는 클릭하지 않는다.
- 쿠팡 로그인·결제·장바구니는 건드리지 않는다.
